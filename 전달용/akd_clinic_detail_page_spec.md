# 대한피부과의사회 회원 사이트 — 클리닉 상세 페이지 개발 사양서

> 회원 클리닉이 별도의 홈페이지를 만들지 않더라도, 본 사이트만으로 의료진·시설·장비·진료 영역을 일반인에게 충분히 소개할 수 있도록 클리닉 상세 페이지를 강화합니다.

## 1. 톤 & 방향성

- 대한피부과의사회 공식 사이트의 톤은 **객관성·전문의 자격·정품 의료기기**가 신뢰의 축입니다.
- 광고성 표현(별점, 가격 강조, 할인, 후기 단독 노출)은 보수적으로 운영합니다.
- 의료법 제56조(의료광고 규제) 준수를 전제로 카피·UI를 작성합니다.

참고 사이트인 BeautsGO는 메디컬 투어리즘 플랫폼이라 광고형 톤이 강합니다. **구조는 참고하되 분위기는 가져오지 않습니다.**

## 3. 섹션별 사양

### 3.1 Hero

- 대표 이미지 슬라이더 (3~5장, lazy load)
- 클리닉명 + 한 줄 슬로건
- 메타 정보: 주소, 전화, 진료시간, 홈페이지 링크
- "의사회 정회원" 인증 배지
- 진료 분야 태그 (사전 정의 enum에서 다중 선택)

### 3.2 진료 철학

- 카드 그리드 (2 × 2)
- 각 카드: 번호 + 제목(20자 이내) + 설명(80자 이내)
- 최대 4개, 0~3개여도 자연스럽게 표시

### 3.3 의료진

- 기존 의사 검색 페이지의 카드 디자인 재사용
- 클리닉 ID로 매칭된 의료진만 표시
- 클릭 시 의사 상세 페이지로 이동

### 3.4 원내 둘러보기 (신규)

**목적**: 회원이 별도 홈페이지를 만들지 않아도, 일반 환자가 시설을 미리 볼 수 있게 합니다.

**UI**:
- 카테고리 필터 탭: `전체 / 접수·대기 / 상담실 / 시술실 / 기타`
- 그리드: 데스크톱 4열 / 태블릿 3열 / 모바일 2열
- 정사각 썸네일 + 좌하단 카테고리 캡션
- 클릭 시 라이트박스 확대 (Photoswipe.js 권장)

**데이터**:
- 사진 최대 20장
- 각 사진: 이미지 파일 + 카테고리 (enum) + 캡션 (선택, 30자)
- 사진이 1장도 없으면 섹션 자체를 숨김 처리

### 3.5 보유 장비 (신규)

**UI**:
- 카드 그리드 (데스크톱 2열, 모바일 1열)
- 각 카드: 썸네일 64×64 + 장비명 + 제조사·모델 + 한 줄 설명 + 진료 영역 태그
- 카드 클릭 시 확대 모달 (장비 상세 설명)

**데이터**:
- 장비명 (필수)
- 제조사·모델 (선택)
- 식약처 허가번호 (선택, 자유 텍스트 입력)
- 사진 (선택)
- 한 줄 설명 (선택, 60자)
- 진료 영역 태그 (선택, enum 다중 선택)

### 3.6 대표 진료

- 진료 카테고리 태그 클라우드 (사전 정의 enum)
- 의료법 고려: 효과 단정·가격 노출 금지

### 3.7 오시는 길

- 지도 임베드 (네이버 지도 또는 카카오맵)
- 주차 안내, 대중교통 정보 (자유 입력 텍스트)

## 5. 기술 스택 권장사항

| 영역 | 권장 |
|------|------|
| 갤러리 라이트박스 | Photoswipe.js v5 |
| 이미지 최적화 | WebP 변환 + lazy loading 필수 |
| 지도 | 네이버 지도 또는 카카오맵 SDK |
| 카테고리 필터 | CSS Grid + 클라이언트 사이드 필터링 (페이지 리로드 X) |

**이미지 비용 주의**: 회원 클리닉 수 × 평균 사진 수만큼 트래픽이 발생합니다. 처음부터 CDN + WebP 자동 변환 파이프라인을 두는 것을 권합니다.

## 6. 단계적 롤아웃

### Phase 1
- Hero 강화 + 진료 철학 + 대표 진료
- 기존 데이터에서 약간만 보강하면 됨
- 회원 입력 부담이 가장 적은 단계

### Phase 2
- 원내 둘러보기 + 보유 장비
- 회원 입력 가이드(예시 사진, 작성 팁) 함께 배포

### Phase 3
- 후기·케이스 노출은 의료법 검토 후 결정
- 다국어(영문) 지원 검토 (외국인 환자 유입 채널)
